자바스크립트에서 객체 배열(Array of Objects)은 대괄호([]) 안에 중괄호({})로 감싼 객체들을 쉼표로 구분해 만듭니다. [1] (https://www.freecodecamp.org/korean/news/javascript-array-of-objects-tutorial/), [2] (https://www.youtube.com/watch?v=vzag-pgBke0&t=20)

1. 기본 생성 방법 (배열 리터럴)

javascript
const users = [
  { id: 1, name: '김철수', age: 25 },
  { id: 2, name: '이영희', age: 30 },
  { id: 3, name: '박민수', age: 28 }
];
코드를 사용할 때는 주의가 필요합니다.
• 대괄호([]): 전체 배열을 감쌉니다.
• 중괄호({}): 개별 객체를 나타냅니다.
• 키:값(key: value): 객체 내부의 속성을 정의합니다. [1] (https://www.youtube.com/watch?v=zwdx7zKU8qw), [2] (https://www.youtube.com/watch?v=vzag-pgBke0&t=20)

2. 빈 배열을 만든 뒤 객체 추가하기 (push)

처음에 빈 배열을 만들고 push() 메서드를 사용해 객체를 나중에 추가할 수도 있습니다. [1] (https://www.freecodecamp.org/korean/news/javascript-array-insert-how-to-add-to-an-array-with-the-push-unshift-and-concat-functions/)
javascript
const products = [];

products.push({ id: 101, title: '노트북', price: 1500000 });
products.push({ id: 102, title: '마우스', price: 35000 });

console.log(products);
코드를 사용할 때는 주의가 필요합니다.

3. 객체를 객체 배열로 변환하기 (Object.entries 등 활용)

이미 존재하는 일반 객체({ a: 1, b: 2 })를 키와 값 형태의 배열로 바꾸고 싶다면 아래 메서드를 사용합니다: [1] (https://developer-talk.tistory.com/303), [2] (https://translate.google.com/translate?u=https://www.quora.com/What-is-the-easiest-way-to-convert-a-JavaScript-object-into-an-array&hl=ko&sl=en&tl=ko&client=sge)
• Object.keys(obj): 객체의 키들을 문자열 배열로 반환합니다.
• Object.values(obj): 객체의 값들을 배열로 반환합니다.
• Object.entries(obj): [키, 값] 쌍의 중첩 배열로 반환합니다. [1] (https://developer-talk.tistory.com/303), [2] (https://velog.io/@gmgmgun/JS-%EA%B0%9D%EC%B2%B4%EB%A5%BC-%EB%B0%B0%EC%97%B4%EB%A1%9C-%EB%B0%94%EA%BE%B8%EB%8A%94-%EB%B0%A9%EB%B2%95)
공식 문서 참고: MDN JavaScript 배열 가이드 [1] (https://developer.mozilla.org/ko/docs/Web/JavaScript/Reference/Global_Objects/Array)
만들려는 객체 배열의 형태(예: 사용자 목록, 상품 데이터 등)나 사용하려는 목적(필터링, 반복문 등)을 알려주시면 알맞은 예제 코드를 작성해 드릴 수 있습니다.
