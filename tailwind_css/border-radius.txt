rounded-[20px]

----------------------------------

top-left
Tailwind CSS에서 왼쪽 상단 모서리(border-top-left-radius)만 둥글게 만들려면 rounded-tl-{크기} 유틸리티 클래스를 사용합니다. 

기본 사용법

html
<div class="rounded-tl-none">0px</div>
<div class="rounded-tl-sm">작은 둥글기</div>
<div class="rounded-tl-md">중간 둥글기</div>
<div class="rounded-tl-lg">큰 둥글기</div>
<div class="rounded-tl-xl">더 큰 둥글기</div>
<div class="rounded-tl-full">완전 둥글게</div>
코드를 사용할 때는 주의가 필요합니다.

임의의 값 지정(Arbitrary Value)

원하는 픽셀이나 rem 값을 직접 넣으려면 대괄호를 사용합니다.
html
<div class="rounded-tl-[20px]">20px 적용</div>
<div class="rounded-tl-[1.5rem]">1.5rem 적용</div>
코드를 사용할 때는 주의가 필요합니다.

참고: 논리적 속성(RTL/LTR 대응)

텍스트 방향에 따라 왼쪽 상단이 달라지는 레이아웃이라면 rounded-ss-{크기}(start-start)를 사용할 수 있습니다.
자세한 클래스 목록은 Tailwind CSS 공식 문서에서 확인할 수 있습니다. 
원하는 둥글기 크기나 사용 중인 Tailwind CSS 버전(v3 또는 v4)을 알려주시면 exact한 클래스나 설정 방법을 안내해 드릴 수 있습니다.
