Tailwind CSS에서 w-4 클래스는 요소의 너비(width)를 1rem(기본 루트 폰트 크기 16px 기준 16px)로 설정하는 유틸리티 클래스입니다.

핵심 의미와 계산 방식

• w-: CSS의 width 속성을 뜻합니다.
• 4: 스페이싱 스케일(간격 단위)의 배수입니다.
• 실제 크기: 기본 설정(1단위 = 0.25rem = 4px) 기준 4 × 0.25rem = 1rem이며, 브라우저 기본 글자 크기가 16px일 때 16px가 됩니다. 
(Tailwind v4에서는 calc(var(--spacing) * 4)로 계산됩니다.) 
자세한 너비 규격은 Tailwind CSS 문서에서 확인할 수 있습니다. 

사용 예시

• 작은 아이콘 크기 지정: <svg class="w-4 h-4 ...">처럼 가로·세로 16px 아이콘을 만들 때 자주 씁니다.
• 인디케이터·점(dot) 요소: 상태 표시용 작은 원형 점이나 구분선 너비를 잡을 때 활용합니다.

관련·대체 클래스

• 정사각형 크기 한 번에 지정: size-4 (너비 1rem과 높이 1rem을 동시에 설정)
• 다른 고정 크기: w-2 (0.5rem / 8px), w-6 (1.5rem / 24px), w-8 (2rem / 32px)
• 비율·유동 너비: w-1/2 (50%), w-full (100%), w-auto (auto)
원하는 사용 맥락(예: 아이콘, 버튼, 레이아웃)이나 원하는 픽셀·비율 크기를 알려주시면 가장 알맞은 Tailwind 클래스를 추천해 드릴 수 있습니다.
