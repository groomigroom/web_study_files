Tailwind CSS에서 hover 상태는 유틸리티 클래스 앞에 hover: 접두사를 붙여 표현합니다. 예를 들어 마우스를 올렸을 때 배경색을 바꾸려면 hover:bg-blue-600처럼 작성합니다. [1] (https://www.youtube.com/watch?v=z9sHOXheE_M&t=35), [2] (https://rudaks.tistory.com/entry/Tailwind-CSS-%EB%B2%88%EC%97%AD-Hover-Focus-%EB%B0%8F-%EA%B8%B0%ED%83%80-%EC%83%81%ED%83%9C)

기본 사용법

원하는 유틸리티 앞에 hover:를 붙이면 마우스 오버 시에만 해당 스타일이 적용됩니다. [1] (https://www.youtube.com/watch?v=z9sHOXheE_M&t=35), [2] (https://rudaks.tistory.com/entry/Tailwind-CSS-%EB%B2%88%EC%97%AD-Hover-Focus-%EB%B0%8F-%EA%B8%B0%ED%83%80-%EC%83%81%ED%83%9C)
html
<button class="bg-blue-500 text-white px-4 py-2 rounded hover:bg-blue-700 transition">
  버튼
</button>
코드를 사용할 때는 주의가 필요합니다.
• 배경색 변경: hover:bg-sky-700
• 글자색 변경: hover:text-gray-900
• 투명도 조절: hover:opacity-75
• 부드러운 전환: transition 또는 duration-200과 함께 사용 [1] (https://www.youtube.com/watch?v=t19h2Ki_DUw&t=2), [2] (https://rudaks.tistory.com/entry/Tailwind-CSS-%EB%B2%88%EC%97%AD-Hover-Focus-%EB%B0%8F-%EA%B8%B0%ED%83%80-%EC%83%81%ED%83%9C), [3] (https://coddy.tech/learn/ko/tailwind/fundamentals/hover_feedback)
hover: 접두사로 버튼과 요소의 배경색, 그림자, 전환 효과를 주는 방법을 영상으로 확인할 수 있습니다:

부모·형제 요소 기준 hover

다른 요소에 마우스를 올렸을 때 스타일을 바꾸려면 group이나 peer를 사용합니다. [1] (https://velog.io/@wlwl99/Tailwind-CSS-%EC%9E%90%EC%8B%9D-%ED%98%95%EC%A0%9C-%EC%9A%94%EC%86%8C%EC%97%90%EA%B2%8C-hover-%ED%9A%A8%EA%B3%BC-%EC%A3%BC%EA%B8%B0)
• 부모 hover 시 자식 스타일 변경: 부모 요소에 group을 넣고, 자식 요소에 group-hover:*를 지정합니다.
• 형제 hover 시 다른 형제 스타일 변경: 기준 요소에 peer를 넣고, 뒤에 오는 형제 요소에 peer-hover:*를 지정합니다. [1] (https://velog.io/@wlwl99/Tailwind-CSS-%EC%9E%90%EC%8B%9D-%ED%98%95%EC%A0%9C-%EC%9A%94%EC%86%8C%EC%97%90%EA%B2%8C-hover-%ED%9A%A8%EA%B3%BC-%EC%A3%BC%EA%B8%B0), [2] (https://fresh-mint.tistory.com/entry/tailwind-CSS-4-%EB%B0%98%EC%9D%91%EC%83%81%ED%83%9C-%EC%84%A0%ED%83%9D%EC%9E%90-%EC%B6%94%EA%B0%80-%EB%B0%A9%EB%B2%95hover-focus-checked-disabled-etc)
html
<div class="group p-4 border rounded hover:border-blue-500">
  <p class="text-gray-700 group-hover:text-blue-600">카드 제목</p>
</div>

<input type="text" class="peer border p-2" placeholder="입력" />
<span class="hidden peer-hover:inline text-sm text-gray-500">안내 문구</span>
코드를 사용할 때는 주의가 필요합니다.
부모 요소에 마우스를 올렸을 때 자식 요소의 스타일을 함께 바꾸는 방법을 영상으로 볼 수 있습니다:

참고할 점

터치 전용 기기에서는 hover가 동작하지 않을 수 있으므로, 키보드 접근성을 위해 focus:나 focus-visible: 스타일도 함께 챙기는 것이 좋습니다. 더 자세한 예시는 Tailwind CSS 번역 - Hover, Focus 및 기타 상태나 Tailwind CSS hover 정리에서 확인할 수 있습니다. [1] (https://coddy.tech/learn/ko/tailwind/fundamentals/hover_feedback), [2] (https://rudaks.tistory.com/entry/Tailwind-CSS-%EB%B2%88%EC%97%AD-Hover-Focus-%EB%B0%8F-%EA%B8%B0%ED%83%80-%EC%83%81%ED%83%9C), [3] (https://rarrit.github.io/til/css/tw-hover/)
적용하려는 UI 요소(예: 버튼, 카드, 메뉴, 이미지)나 원하는 변화(색상, 크기 확대, 밑줄, 모달/툴팁 노출 등)를 알려주시면 맞는 클래스 조합을 바로 짜드릴 수 있습니다.
