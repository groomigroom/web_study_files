fetch() 함수는 첫번째 인자로 URL, 
두번째 인자로 옵션 객체를 받고, 
Promise 타입의 객체를 반환합니다. 
반환된 객체는, API 호출이 성공했을 경우에는 응답(response) 객체를 resolve하고, 
실패했을 경우에는 예외(error) 객체를 reject합니다.

fetch(url, options)
  .then((response) => console.log("response:", response))
  .catch((error) => console.log("error:", error));

GET 호출


네. <form method="get">과 동일하게 URL 쿼리스트링에 폼 데이터를 붙여서 GET 요청을 보내면 됩니다.

예를 들어 HTML이:

<form action="/search" method="get">
  <input name="keyword" value="apple">
  <input name="page" value="2">
  <button type="submit">검색</button>
</form>


이면 브라우저는 대략 다음 요청을 보냅니다.

GET /search?keyword=apple&page=2


이를 fetch()로 하면:

const params = new URLSearchParams({
  keyword: "apple",
  page: "2"
});

fetch(`/search?${params}`)
  .then(response => response.json())
  .then(data => console.log(data));


또는 async/await:

const params = new URLSearchParams({
  keyword: "apple",
  page: "2"
});

const response = await fetch(`/search?${params}`);
const data = await response.json();

실제 <form>의 데이터를 그대로 사용하려면

이 방법이 가장 <form>의 GET 동작과 비슷합니다.

<form id="searchForm">
  <input name="keyword" value="apple">
  <input name="page" value="2">
  <button>검색</button>
</form>

<script>
const form = document.querySelector("#searchForm");

form.addEventListener("submit", async (e) => {
  e.preventDefault();

  const params = new URLSearchParams(new FormData(form));

  const response = await fetch(`/search?${params}`);
  const data = await response.json();

  console.log(data);
});
</script>


즉 핵심은:

new URLSearchParams(new FormData(form))


으로 <form>의 데이터를 keyword=apple&page=2 같은 쿼리스트링으로 변환한 뒤,

fetch(`/search?${params}`)


하는 것입니다.

참고로 fetch("/search", { method: "GET", body: ... })처럼 GET 요청의 body에 폼 데이터를 넣는 방식은 일반적인 HTML form의 GET 동작과 다릅니다. GET form처럼 하려면 URL의 query string을 사용하세요.

POST 방식

<form id="loginForm">
  <input name="username" value="apple">
  <input name="password" type="password" value="1234">
  <button type="submit">로그인</button>
</form>

<script>
const form = document.querySelector("#loginForm");

form.addEventListener("submit", async (e) => {
  e.preventDefault();
  //preventDefault() 메서드는 어떤 이벤트를 명시적으로 처리하지 않은 경우, 해당 이벤트에 대한 사용자 에이전트의 기본 동작을 실행하지 않도록 지정합니다.

  const formData = new FormData(form);

  const response = await fetch("http://localhost:3000/login", {
    method: "POST",
    body: formData
  });

  const data = await response.json();

  console.log(data);
});
</script>
