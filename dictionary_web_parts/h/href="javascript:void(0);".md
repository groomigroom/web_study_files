href="javascript:void(0);"는 사실 타임리프(Thymeleaf) 전용 문법이 아니라 순수 자바스크립트(JavaScript)와 HTML 문법입니다.
타임리프 템플릿 안에서 이 코드가 사용되는 이유는 "이 링크(<a> 태그)를 클릭했을 때, 페이지를 이동하거나 새로고침하지 말고 아무 일도 일어나지 않게 하라"는 뜻입니다.
------------------------------
## 1. 왜 이렇게 쓰나요?
HTML에서 <a> 태그는 기본적으로 다른 페이지로 이동하는 역할을 합니다. 하지만 웹 개발을 하다 보면 아래와 같은 상황이 생깁니다.

* 링크 모양(손가락 커서, 파란 글씨 등)은 유지하고 싶을 때
* 클릭했을 때 페이지 이동이 아니라, 내가 만든 자바스크립트 함수(팝업 띄우기, 좋아요 버튼 클릭 등)만 실행하고 싶을 때

이때 href에 이동할 주소 대신 javascript:void(0);를 적어두면, 브라우저의 기본 이동 기능을 무효화(Mute) 시킬 수 있습니다.
## 2. 타임리프 파일 안에서의 실제 사용 패턴
보통 타임리프에서는 이 코드와 함께 th:onclick 또는 클래스 선택자를 활용한 jQuery/Vanilla JS 이벤트를 묶어서 사용합니다.
예시 1: 클릭 시 자바스크립트 함수 호출

<!-- 클릭해도 페이지가 위로 튕기거나 이동하지 않고, deleteItem() 함수만 깔끔하게 실행됩니다. -->
<a href="javascript:void(0);" th:onclick="|deleteItem('${item.id}')|">삭제</a>

예시 2: 페이징 처리 (스프링 부트 쇼핑몰/게시판 등에서 자주 등장)

<!-- 페이지 번호를 눌렀을 때 주소가 바뀌는 게 아니라, 자바스크립트로 폼을 제출할 때 -->
<a href="javascript:void(0);" th:data-page="${page}" class="page-link">2</a>

------------------------------
## 3. 유사품: href="#" 과의 결정적인 차이점
많은 개발자들이 href="#"도 자주 사용합니다. 둘은 비슷해 보이지만 중요한 차이가 있습니다.

* href="#": 클릭하면 주소창 뒤에 #이 붙으면서 페이지 최상단(맨 위)으로 화면이 스크롤(점프) 가 되어버립니다. 화면 중간쯤에서 버튼을 눌렀는데 맨 위로 튕겨 올라가면 사용자 경험에 좋지 않습니다.
* href="javascript:void(0);": 클릭해도 화면이 위로 튕기지 않고 현재 스크롤 위치를 그대로 유지합니다. (void(0)이 자바스크립트에서 '아무것도 반환하지 마라(undefined)'라는 의미이기 때문입니다.)

------------------------------
혹시 이 코드가 들어간 링크를 클릭했을 때 원하는 자바스크립트 로직이 실행되지 않거나, 타임리프 문법 에러가 발생하고 계시나요? 연결된 전체 코드를 보여주시면 원인을 같이 짚어드릴 수 있습니다!
